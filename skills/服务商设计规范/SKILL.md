# 服务商设计规范 Skill

## 用途

在你需要做以下事情时使用本 Skill：

1. 从 0 生成符合“服务商设计规范”的页面。
2. 将已有页面改造成“服务商设计规范”风格。
3. 生成卡片式列表页 + 右侧固定会话区布局。
4. 生成详情工作台（对象摘要 + 中央内容分区 + 右侧 AI/协作）。

## 触发词

以下关键词都应触发本 Skill：

- `按服务商设计规范`
- `服务商设计规范`
- `按服务商风格`
- `PC共创设计规范`（兼容旧称）

## 必读规范文件

执行本 Skill 时，优先读取并遵循：

1. `../../PC共创-网页设计规范.md`
2. `../../pc-cocreate.visual-style.md`

如果当前工作区没有这两个文件，按本 Skill 内置规则执行，并在输出中说明使用了“内置默认规则”。

## 内置默认规则（摘要）

### 视觉基调

- 浅灰蓝背景，白色面板，高信息密度。
- 主色为紫色，仅用于主操作与选中态。
- 状态色：蓝（信息）、绿（成功）、橙（提醒）、红（风险）。
- 小圆角、细边框、轻阴影，不做营销风 hero。

### 布局骨架

- 左侧窄导航 + 顶部工具栏 + 中央业务区 + 右侧协作/会话区。
- 列表页：3 列卡片网格优先。
- 详情页：对象摘要栏 + 中央详情区 + 右侧 AI/协作栏。

### 组件约束

- 按钮高 `32-36px`，圆角 `8px`。
- 卡片圆角 `10-12px`，边框 `1px #E8ECF3`。
- 状态标签高 `20-24px`，使用浅底色。
- 进度条高 `4-6px`，紫色进度。
- 右侧会话区固定宽度（推荐 `300-380px`）。

## 输出要求

当用户要求“生成页面”时：

1. 直接输出可运行页面（HTML/CSS/JS 或项目内对应技术栈代码）。
2. 页面必须包含完整状态：默认、hover、active、disabled。
3. 页面必须可搜索/筛选（如有列表数据）。
4. 明确哪些字段是可配置的数据字段。

当用户要求“改造页面”时：

1. 保留原业务结构和字段语义。
2. 仅替换视觉层与交互层，不随意改业务文案。
3. 给出改造前后关键变化摘要（颜色、布局、组件、交互）。

## 页面模式模板

### 模式 A：卡片列表 + 右侧固定会话

- 顶部：页签、搜索、筛选、主操作按钮。
- 中央：3 列卡片网格；卡片包含状态、进度、主字段、操作按钮。
- 右侧：固定会话区，含头像条、消息流、建议卡、输入区。

### 模式 B：详情工作台

- 顶部：返回、对象名称、状态、主操作。
- 左/中：对象摘要、阶段进度、记录、材料、分析建议。
- 右侧：AI 协作建议、评论、待办动作。

## 禁止事项

1. 不要生成营销官网式大横幅布局。
2. 不要大面积使用紫色背景。
3. 不要使用厚重阴影、玻璃拟态泛滥、装饰性光斑。
4. 不要把 B 端信息密度做得过低。
5. 不要省略业务字段，只做视觉空壳。

## 建议工作流

1. 先识别用户是“列表页”还是“详情页”。
2. 再映射字段到卡片/表单/摘要分区。
3. 按规范落地颜色与组件。
4. 最后检查响应式与文本不溢出。
