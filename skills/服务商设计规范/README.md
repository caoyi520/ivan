# 服务商设计规范 Skill 使用说明

## 位置

Skill 主文件：

- `skills/服务商设计规范/SKILL.md`

依赖规范：

- `PC共创-网页设计规范.md`
- `pc-cocreate.visual-style.md`

## 如何在其他项目复用

1. 将 `服务商设计规范` 文件夹复制到目标项目的 skill 目录（或你的统一 skill 目录）。
2. 同时复制两份规范文件，或在 `SKILL.md` 中改成你的实际路径。
3. 在对话中使用触发词：
   - `按服务商设计规范`
   - `服务商设计规范`
   - `按服务商风格`

## 推荐调用句式

```text
按服务商设计规范，帮我生成一个客户认款卡片列表页，右侧固定智能会话区。
```

```text
按服务商设计规范，把这个详情页改成对象摘要 + 中央内容分区 + 右侧协作建议。
```
