停止服务配置抽屉原型规格

1. 业务与功能

1.1 核心目标

本原型用于企业服务后台配置“合同到期后停止服务”的规则。原规则为订单合同期到期后自动停止服务；新增配置后，运营人员可设置合同到期后延后若干个月再停止服务，用于覆盖续约沟通、宽限期管理和客户数据保留场景。

1.2 功能清单

  • 右侧抽屉配置：从服务策略列表进入，右侧抽屉承载完整配置表单。
  • 规则启停：支持开启或关闭“延后停止服务”配置。
  • 延后月数：合同到期后可延后 1-24 个月停止服务。
  • 生效范围：支持全部企业、新签/续签合同、指定服务包三种范围。
  • 到期提醒：支持配置合同到期前和停止服务前的提醒节点。
  • 服务停止动作：支持配置停止服务后的系统动作，如冻结新增业务、保留只读访问、发送通知。
  • 实时预览：基于示例合同到期日，实时计算停止服务日期和规则摘要。
  • 影响企业列表：展示近期将受规则影响的企业，用于运营确认。
  • 保存反馈：保存后展示成功反馈，并触发 Axure 事件。

1.3 交互要点

  • 点击“停止服务配置”或“打开配置”时，抽屉从右侧展开。
  • 关闭抽屉时保留当前编辑状态，再次打开可继续查看。
  • 开启延后停止后，延后月数输入框可编辑；关闭后回退到“合同到期当日停止服务”。
  • 修改延后月数时，预览区同步更新停止服务日期和时间线。
  • 点击“保存配置”后触发 onSaveStopServiceConfig，payload 为当前配置 JSON 字符串。
  • 点击“恢复原规则”后将延后月数重置为 0，并关闭延后停止开关。

2. 内容规划

2.1 信息架构

停止服务配置
├── 背景工作台
│   ├── 顶部：页面标题、策略状态、打开配置
│   ├── 策略摘要：原停止规则、新停止规则、影响企业、待续约合同
│   └── 策略列表：自动开通、到期续费、停止服务配置、数据保留
└── 右侧抽屉
    ├── 抽屉头：标题、状态、关闭
    ├── 当前规则摘要
    ├── 配置表单：启用、延后月数、生效范围、提醒节点、停止动作
    ├── 规则预览：示例合同日期、停止日期、时间线
    ├── 影响企业列表
    └── 底部操作：取消、恢复原规则、保存配置

2.2 数据来源

  • 默认示例数据内置在原型中。
  • 可通过 data.companies 覆盖影响企业列表。
  • 可通过 config.defaultDelayMonths 设置初始延后月数。

2.3 关键字段

  • enabled：是否启用延后停止服务。
  • delayMonths：合同到期后延后停止月数。
  • scope：规则生效范围。
  • reminderNodes：提醒节点。
  • freezeNewBusiness：停止后是否冻结新增业务。
  • readonlyAccess：停止后是否保留只读访问。
  • notifyOwner：停止时是否通知客户负责人。

3. 布局与结构

3.1 整体布局

  • 页面采用 B 端后台配置工作台布局，背景为浅灰蓝工作区。
  • 主内容区为服务策略看板，右侧抽屉宽度约 520px。
  • 抽屉内容分为表单区和预览区，底部操作固定，便于长内容下保存。

3.2 响应式适配

  • 桌面端：抽屉覆盖右侧 520px，左侧工作台仍可见。
  • 窄屏端：抽屉宽度降为 100vw，表单和预览纵向排列。
  • 表格和策略列表在小屏下横向滚动或单列展示。

4. 视觉规范

4.1 设计规范来源

使用项目 服务商设计规范 的 B 端工作台规则，并参考 rules/design-guide.md 与 rules/development-guide.md。

4.2 自定义设计要点

  • 背景：#F5F7FB，面板：#FFFFFF，边框：#E8ECF3。
  • 主色：#7566F1，仅用于主按钮、选中态和关键数值。
  • 风险/提醒：橙色用于“即将停止”“待续约”等提示。
  • 抽屉保持高信息密度，避免营销式大标题。
  • 表单控件高度控制在 32-36px，圆角不超过 8px。

4.3 组件状态

  • 默认态：白色面板、细边框、弱阴影。
  • 悬停态：策略项和表格行轻微高亮。
  • 选中态：当前策略使用主紫描边和浅紫底。
  • 禁用态：关闭延后停止后，延后月数输入置灰。
  • 成功态：保存后以消息反馈展示。
  • 提醒态：影响企业中临近停止的合同使用橙色标签。

5. Axure API 说明

5.1 事件列表

事件名称 Payload 类型 触发时机
onOpenStopServiceConfig string 打开抽屉
onCloseStopServiceConfig string 关闭抽屉
onStopServiceConfigChange string 表单配置变化
onSaveStopServiceConfig string 保存配置
onResetStopServiceConfig string 恢复原规则

5.2 动作列表

动作名称 Params 类型 功能描述
open_drawer 无 打开右侧抽屉
close_drawer 无 关闭右侧抽屉
set_delay_months number 设置延后停止月数
save_config 无 保存当前配置
reset_to_original 无 恢复合同到期即停止

5.3 变量列表

变量名称 类型 说明
drawer_open boolean 抽屉是否打开
enabled boolean 是否启用延后停止服务
delay_months number 延后停止月数
stop_date_preview string 示例停止服务日期
affected_company_count number 受影响企业数量
