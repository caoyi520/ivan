AI 使用反馈周报推荐结构

一、使用工具与 Skill

  • 写清使用了哪些工具。
  • 写清使用了哪些项目规范、Skill 或自动化流程。
  • 不只列名称，要说明用途。

二、结合上周评分后的改进点

  • 摘要上周得分和主要扣分点。
  • 本周逐项回应。
  • 用“上周问题 → 本周动作 → 证据文件”表达。

三、关键 Prompt / 核心思路

  • 写最核心的 Prompt。
  • 说明为什么这样组织任务。
  • 如果使用了 Obsidian 或自动化流程，要写入 Prompt 思路。

四、最终产出

按项目分段描述：

  • 业务目标。
  • 核心能力。
  • 相关文件。
  • 截图证据。
  • 可点击交互 HTML。

自动化项目按以下结构描述：

  • 触发器。
  • 自动执行任务。
  • 产物。
  • 失败兜底。
  • 人工介入点。

Obsidian 应用按以下结构描述：

  • 知识库结构。
  • 本周相关笔记。
  • 如何支撑本周判断。
  • 当前证据不足的地方。

五、效果评估

  • 预期目标。
  • 实际结果。
  • 结果与预期差距。

避免只写“达成预期”，要写具体差距和下一步。

六、前后对比

用表格表达：

对比项 上周状态 本周改进

建议对比项：

  • 工作流证据。
  • 原型证据。
  • 交互深度。
  • 自动化沉淀。
  • Obsidian 应用。
  • Skill 复用。

七、经验沉淀

  • 有效 Prompt。
  • 推荐工作流。
  • 常见问题与解决方案。
  • 可复用 Skill。

八、本周可提交附件

列出：

  • 周报正文。
  • 可点击版 zip。
  • 截图目录。
  • 原型 HTML。
  • 关键源文件。
  • Skill 包。
