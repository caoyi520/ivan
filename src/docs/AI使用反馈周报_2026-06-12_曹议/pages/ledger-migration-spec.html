账套导入系统原型规格说明

1. 业务与功能

1.1 页面定位

账套导入系统面向企业客户自己使用，用于把某一财务软件下商户/服务商可访问的账套数据采集出来，再导入到新的财务软件账套中。

当前版本支持的财务软件为：

  • 猪哥云
  • 财税合规AI服务系统

页面不再按“账号所属系统”登录。用户先登录导账系统，再分别授权源财务软件和新财务软件。

1.2 核心目标

  • 用户登录导账系统，不需要区分账号所属财务软件。
  • 登录后进入导账工作台，默认展示当前用户所有导账任务。
  • 用户可在任务列表查看采集中、待导入、导入成功等任务状态，并从列表发起新的导账任务。
  • 用户选择要采集的财务软件名称。
  • 用户输入该财务软件下的商户/服务商、账号、密码，提交后创建异步采集任务。
  • 采集完成后，用户输入新财务软件下的商户/服务商、账号、密码。
  • 目标授权通过后，用户选择导入方式，并勾选要导入的数据。
  • 导入成功后，系统生成导入记录，支持后续追溯。

1.3 功能清单

  • 登录页：仅包含导账系统账号、密码，不区分所属系统。
  • 任务列表：展示当前用户所有导账任务，包含状态、源/目标系统、商户/服务商、数据量、更新时间和操作入口。
  • 源财务软件授权：选择财务软件名称，输入商户/服务商、账号、密码。
  • 异步采集任务：展示任务执行中进度、权限校验、账套发现和数据采集日志。
  • 目标财务软件授权：采集完成后，选择新财务软件，输入新财务软件下商户/服务商、账号、密码。
  • 导入方式：支持“跳过已创建账套的企业”和“覆盖已创建账套的企业”。
  • 数据选择：按财务数据、基础资料、智能记账、其他四组选择要导入的数据。
  • 导入确认：弹窗确认导入方式、授权路径、数据范围和记录数。
  • 导入成功：展示导入成功状态，并写入右侧导入记录。
  • 记录留痕：右侧固定区域展示导入记录、导入策略、审计入口和导出入口。

1.4 交互要点

  • 点击“登录”进入导账工作台任务列表。
  • 点击“发起导账任务”进入源财务软件采集授权。
  • 任务状态为“待导入”时可点击“继续导入”；状态为“采集中”时可查看采集进度；状态为“导入成功”时可查看记录。
  • 源财务软件选择后，新财务软件默认取另一套支持软件，也允许在目标授权步骤调整。
  • 点击“提交并开始采集”后进入异步任务状态，模拟完成后进入目标授权。
  • 目标授权通过后进入“选择导入方式和数据”。
  • 用户先选择导入方式，再按分类勾选要导入的数据。
  • “跳过已创建账套的企业”用于避免覆盖目标系统已有企业账套；“覆盖已创建账套的企业”用于用采集数据更新已有企业账套。
  • 点击“导入所选数据”弹出二次确认。
  • 点击“开始导入”后进入导入中状态，完成后生成导入成功记录。

2. 内容规划

2.1 信息架构

账套导入系统
├── 登录页
│   ├── 系统说明
│   └── 导账系统账号密码
└── 导账工作台
    ├── 顶部工具栏
    │   ├── 页面标题与说明
    │   ├── 发起导账任务
    │   └── 导入所选数据
    ├── 中央业务区
    │   ├── 任务列表
    │   ├── 六步流程条
    │   ├── 源软件授权表单
    │   ├── 异步采集任务进度
    │   ├── 新软件授权表单
    │   ├── 导入方式与数据选择
    │   ├── 导入中状态
    │   └── 导入成功结果
    └── 右侧导入记录
        ├── 当前流程说明
        ├── 采集结果摘要
        ├── 导入策略
        ├── 成功记录列表
        └── 审计/授权/导出入口

2.2 账套数据范围

默认采集并展示以下可导入数据：

分组 数据项
财务数据 财务初始余额、会计科目、凭证记录、辅助核算
基础资料 财务初始余额、银行账户、科目、辅助核算
智能记账 销项发票、进项发票、费用报销、无票收入、银行、工资
其他 币别、附件、小计

2.3 数据来源与关键字段

数据源为示例账套采集结果，可由外部 data.ledger_sets 与 data.ledger_items 覆盖。

ledger_sets

字段 说明
id 账套唯一标识
software 财务软件名称
merchant 商户/服务商
name 账套名称
company 企业名称
period 账套期间
standard 会计准则
voucherCount 凭证数量

ledger_items

字段 说明
id 数据项唯一标识
ledgerSetId 所属账套 id
category 数据分类
name 数据名称
period 所属期间
count 记录数量
amount 金额合计
status ready、warning、blocked、imported
issues 异常或复核说明

2.4 可配置字段

  • config.title：页面标题，默认“账套导入系统”。
  • config.subtitle：页面说明，默认“采集源财务软件账套数据，并导入到新的财务软件账套”。
  • data.ledger_sets：采集到账套列表。
  • data.ledger_items：采集到账套数据项。

3. 布局与结构

3.1 整体布局

  • 登录页：左侧说明区 + 右侧登录卡片。
  • 工作台：顶部工具栏 + 中央业务区 + 右侧导入记录。
  • 中央业务区：默认展示任务列表；发起或继续任务后，通过流程条和当前步骤表单组织导账流程。
  • 右侧记录区：宽度 340px，持续展示导入记录和策略提醒。

3.2 响应式适配

  • 宽屏桌面：中央业务区与右侧导入记录并排。
  • 中等屏幕：右侧记录区下移，导入数据分组改为单列。
  • 小屏幕：顶部工具栏、右侧记录区与表单按单列展示。
  • 中文文本使用 word-break: keep-all 与 text-wrap: pretty，避免孤字断行。

4. 视觉规范

4.1 设计规范来源

使用“服务商设计规范”Skill。当前工作区未提供 PC共创-网页设计规范.md 与 pc-cocreate.visual-style.md，因此本原型采用该 Skill 的内置默认规则。

4.2 设计要点

  • 背景：浅灰蓝 #F4F7FC。
  • 面板：白色卡片、细边框、轻阴影。
  • 主色：紫色 #6D5EF7，用于主按钮、流程高亮和关键操作。
  • 状态色：成功绿、提醒橙、风险红、信息蓝。
  • 信息密度：按 B 端任务工作台处理，不做营销式大横幅。
  • 交互：突出任务列表、异步任务、授权表单、导入方式、数据选择和导入记录。

4.3 组件状态

  • 默认态：白底卡片、灰蓝背景、细边框。
  • 悬停态：主按钮、表单控件和记录入口颜色加深或底色高亮。
  • 选中态：当前流程步骤高亮。
  • 禁用态：未到步骤时导入按钮禁用；暂不可导数据不可勾选。
  • 加载态：采集和导入时展示动态进度条与日志。
  • 空状态：搜索无结果时表格展示空状态。
  • 完成态：导入成功后数据状态变为“已导入”，右侧记录新增成功记录。

5. Axure API 说明

5.1 事件列表

事件名称 触发时机 Payload
on_login_submit 提交导账系统登录 登录账号 JSON 字符串
on_source_collect_submit 提交源财务软件采集授权 源软件、商户/服务商和账号 JSON 字符串
on_collect_finish 异步采集任务完成 采集到账套和数据 JSON 字符串
on_target_auth_submit 提交目标财务软件授权 目标软件、商户/服务商和账号 JSON 字符串
on_selection_change 选择导入方式或导入数据 当前选择 JSON 字符串
on_import_start 开始导入 导入任务 JSON 字符串
on_import_success 导入成功并生成记录 导入记录 JSON 字符串

5.2 动作列表

动作名称 说明
submit_login 进入导账任务列表
start_new_task 从任务列表发起新的导账任务
submit_source_collect 提交源软件授权并创建异步采集任务
finish_collect 直接进入目标财务软件授权
submit_target_auth 提交目标软件授权并进入导入选择
import_selected 导入当前选择的数据
reset_flow 新建采集任务

5.3 变量列表

变量名称 说明
current_mode 当前页面状态
source_software 源财务软件
target_software 目标财务软件
source_merchant 源财务软件下商户/服务商
target_merchant 目标财务软件下商户/服务商
import_mode 导入方式：跳过或覆盖已创建账套企业
selected_items 待导入数据项
import_records 导入记录列表
