财税管理后台登录页

📋 业务与功能

1.1 核心目标

财税管理后台登录页面面向企业财务、税务专员、代账服务人员与管理者，用于安全进入申报、票据、凭证、风险预警等财税工作台。页面目标是在登录前建立“合规、可靠、可追溯”的信任感，同时减少用户在多公司、多租户场景下的登录误入。

1.2 功能清单

  • 品牌与系统定位：展示“云账税控台”名称、企业级安全与合规标签。
  • 租户选择：支持选择企业主体，避免财务人员进入错误账套。
  • 账号登录表单：包含手机号/工号、密码、验证码与记住设备。
  • 登录反馈：提交时显示加载状态，成功后触发外部事件。
  • 辅助入口：忘记密码、统一身份登录、CA/税控盘入口。
  • 可信信息展示：展示合规状态、申报倒计时、票据同步、风险提示等登录前摘要。

1.3 交互要点

  • 切换企业主体：刷新当前租户状态，并触发 onTenantChange 事件。
  • 点击“登录工作台”：校验必填字段，按钮进入加载态，完成后触发 onLoginSubmit 事件。
  • 点击“忘记密码”：触发 onForgotPassword 事件。
  • 点击“统一身份登录”：触发 onSsoLogin 事件，用于对接企业 SSO 或 CA 登录。
  • 输入框聚焦：展示清晰聚焦描边，满足键盘操作与可访问性要求。

🎨 布局与结构

3.1 整体布局

  • 布局模式：桌面端双栏登录网关，左侧为业务信任摘要，右侧为登录表单。
  • 容器宽度：全屏流式布局，内容最大宽度约 1180px。
  • 关键尺寸：
    • 左侧摘要区：桌面端约 56% 宽度，承载品牌与状态信息。
    • 右侧登录区：桌面端约 420px 宽度，保持表单聚焦。
    • 登录输入框：高度不低于 44px，满足触控与可访问性。

3.2 响应式适配

  • 桌面端（≥1200px）：左右双栏，左侧摘要与右侧登录同时可见。
  • 平板端（768-1199px）：保持双栏但收紧边距，左侧摘要减少装饰层级。
  • 移动端（<768px）：切换为单列，登录表单优先展示，业务摘要置于表单下方。

🎨 视觉规范

4.1 设计规范来源

设计规范来源：主题 /src/themes/antd-new + 用户指定 Skill /Users/caoyi/.codex/skills/ui-ux-pro-max/SKILL.md

说明：基础组件遵循 Ant Design 中后台规范；视觉方向使用 ui-ux-pro-max 生成的 Enterprise Gateway / Accessible & Ethical 方案，并根据中文财税后台场景调整为默认浅色、高信任、低干扰界面。

4.2 自定义设计要点

自定义色彩：

  • 深海军蓝 #1E3A5F：品牌标识、标题和关键边框。
  • 合规绿 #059669：安全状态、通过校验、主操作强调。
  • 票据琥珀 #B7791F：申报提醒与待复核风险。
  • 账本纸白 #F7F3EA：左侧账本纹理背景，传达财税文档感。

自定义尺寸：

  • 主容器最小高度：100dvh
  • 登录面板圆角：8px
  • 输入框最小高度：44px
  • 桌面内容最大宽度：1180px

其他自定义规范：

  • 不使用表情符号作为结构图标，统一使用 Ant Design 图标。
  • 中文文案使用 word-break: keep-all，避免孤字换行。
  • 减少纯装饰动画，状态变化仅使用 150-240ms 微交互。

4.3 组件状态

  • 默认态（default）：浅色背景、明确分区、主按钮使用合规绿。
  • 悬停态（hover）：按钮和辅助入口颜色加深，左侧信息块轻微边框强化。
  • 聚焦态（focus）：输入框显示高对比聚焦环，支持键盘可见定位。
  • 禁用态（disabled）：登录提交期间按钮不可重复点击，并显示加载态。
  • 错误态（error）：表单校验在字段下方展示清晰中文错误。
  • 加载态（loading）：登录按钮展示加载状态，避免重复提交。

⚙️ Axure API 说明

5.1 事件列表（eventList）

事件名称 Payload 类型 触发时机 说明
onLoginSubmit string 登录表单提交成功 返回登录表单与租户信息 JSON 字符串
onTenantChange string 切换企业主体 返回当前企业主体 JSON 字符串
onForgotPassword string 点击忘记密码 返回当前租户 JSON 字符串
onSsoLogin string 点击统一身份登录 返回当前租户 JSON 字符串

5.2 动作列表（actionList）

动作名称 Params 类型 参数说明 功能描述
submit_login string 可为空 触发一次模拟登录提交
switch_tenant string 企业主体 id 切换当前企业主体

5.3 变量列表（varList）

变量名称 类型 默认值 说明
current_tenant object 第一家企业主体 当前选中的企业主体
login_status string idle 当前登录状态

命名规范：使用 snake_case（小写字母、数字、下划线）

5.4 配置项列表（configList）

配置项名称 类型 默认值 说明
systemName string 云账税控台 系统名称
subtitle string 企业财税合规管理后台 系统说明
securityText string 已启用等保二级访问审计 登录安全提示

5.5 数据项列表（dataList）

数据结构：

{
  tenants: Array<{
    id: string;
    name: string;
    taxNo: string;
    status: string;
  }>;
  noticeItems: Array<{
    label: string;
    value: string;
    tone: 'safe' | 'warning' | 'info';
  }>;
}
