报表规则模板配置原型规格

📋 业务与功能

1.1 核心目标

本原型面向后台会计，用于按会计准则维护客户新建账套时自动带入的初始报表规则模板。模板发布后仅影响未来新建账套，不覆盖已有客户账套；客户在自己账套内仍可自定义修改各项报表规则。

关联 PRD：src/docs/后台报表规则模板配置PRD.md

1.2 功能清单

  • 准则切换：首期支持企业会计准则、小企业会计准则。
  • 报表范围：首期支持资产负债表、利润表。
  • 总览页：展示准则版本、已配置报表数、生效规则数、待发布变更、报表矩阵、校验预览和真实报表预览。
  • 配置页：选择准则和报表后进入表样配置，按真实表样维护项目行规则。
  • 科目取数规则：普通项目行可绑定多个科目，每个科目支持搜索选择、+ / - 运算符和取值口径。
  • 表内公式规则：合计行支持通过表内项目相加减形成公式。
  • 发布校验：发布前弹窗展示报表平衡、科目漏绑、重复科目、公式引用和影响范围确认。
  • 发布回流：确认发布后清空待发布变更并返回总览页。

1.3 交互要点

  • 点击准则卡片：切换当前准则并刷新报表矩阵、规则编排和预览。
  • 点击报表名称：切换右侧真实报表预览。
  • 点击报表“配置”：进入配置页，并按报表类型加载对应真实表样。
  • 配置页点击项目行：右侧表单显示该项目行配置。
  • 修改项目名称、行次、取值规则、数据来源：实时同步当前行摘要和表样。
  • 普通项目行支持新增/删除科目规则；合计行显示表内公式，不要求绑定科目。
  • 点击发布配置：打开发布前校验弹窗；确认后发布并返回总览。

📊 内容规划

2.1 信息架构

报表规则模板配置
├── 页面 1：总览页
│   ├── 顶部工具栏：搜索、保存草稿、导出模板包、发布配置
│   ├── 指标区：准则版本、已配置报表数、生效规则、待发布变更
│   ├── 左侧准则列表
│   ├── 中部配置区：报表矩阵 / 规则编排 / 校验预览
│   └── 右侧真实报表预览
└── 页面 2：报表配置页
    ├── 操作条：返回、新增行、删除行、保存表样、发布配置
    ├── 左侧真实表样
    │   ├── 资产负债表：左右结构
    │   └── 利润表：纵向结构
    ├── 当前行规则摘要
    └── 右侧行项目配置表单

2.2 数据来源

  • 示例数据内置于原型，可通过 data.standards 覆盖。
  • 数据对象包括会计准则、报表模板、规则分组、规则项和报表项目行。
  • 首期只展示企业会计准则、小企业会计准则，以及资产负债表、利润表。

2.3 关键字段

  • AccountingStandard.id/name/version
  • ReportTemplate.id/name/code/status/enabled/linkedRules
  • ReportItem.id/item/lineNo/rowType/ruleType/ruleExpression/source
  • SubjectRuleLine.subject/operator/valueRule

🎨 布局与结构

3.1 整体布局

  • 总览页：左侧窄导航 + 顶部工具栏 + 指标区 + 三栏工作台。
  • 配置页：顶部操作条 + 左侧表样画布 + 右侧行配置面板。
  • 发布校验：居中弹窗，展示校验结论和影响范围说明。

3.2 响应式适配

  • 桌面端：总览页三栏并排，配置页表样与右侧表单并排。
  • 平板端：准则列表、配置区、预览区上下排列。
  • 移动端：工具栏换行，表格横向滚动，配置表单置于表样下方。

🎨 视觉规范

4.1 设计规范来源

使用项目技能 服务商设计规范 的 B 端工作台规则：浅灰蓝工作区、白色高密度面板、主紫选中态、细边框、轻阴影、紧凑工具栏。

4.2 自定义设计要点

  • 主色：#7566F1，用于主按钮、选中态和关键进度。
  • 背景：#F5F7FB，避免整页纯白。
  • 面板：白色背景、#E8ECF3 边框、12px 圆角。
  • 状态色：成功绿、提醒橙、风险红、信息蓝。
  • 报表表样保留真实列名，但金额列展示规则口径而非具体金额。

4.3 组件状态

  • 默认态：白色面板、低对比边框。
  • 悬停态：准则卡片、规则项、表格行轻微高亮。
  • 选中态：准则卡片和项目行使用主紫描边/浅紫底。
  • 禁用态：停用规则降低透明度。
  • 加载态：发布按钮显示 loading。
  • 异常态：校验风险使用橙色提示。
  • 完成态：校验通过和发布成功使用绿色提示。
