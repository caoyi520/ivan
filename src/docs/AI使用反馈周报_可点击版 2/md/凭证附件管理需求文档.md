# 财务记账系统凭证附件上传迭代需求文档

## 0. 文档信息

- 版本：`v1.0`
- 状态：`Draft`
- 需求类型：功能迭代
- 关联模块：录凭证、查凭证、编辑凭证、凭证打印、附件预览
- 目标用户：财务人员、审核人员、账套管理员、审计/查看人员
- 更新时间：`2026-06-01`

## 1. 背景与目标

### 1.1 背景

在财务记账系统中，凭证是会计分录的正式记录，附件是证明凭证业务真实性和金额来源的原始依据。当前系统已在查凭证场景中存在“附单据”相关能力说明，但业务迭代要求进一步覆盖凭证全流程：录凭证时可上传附件，查凭证时可查看和补充附件，编辑凭证时可维护附件，并且附件变化会影响凭证打印、附件打印和相关展示口径。

### 1.2 业务目标

1. 支持财务人员在录凭证、查凭证、编辑凭证三个核心场景中手动上传附件。
2. 建立凭证与附件的稳定绑定关系，保证后续审核、查账、结账和审计追溯时可查看原始依据。
3. 在凭证列表、凭证详情、编辑页和打印场景中统一展示附件数量和附件状态。
4. 保证附件新增、删除、替换等操作有权限控制和操作留痕。

### 1.3 非目标

1. 本期不做附件自动识别生成凭证分录。
2. 本期不做 OCR 自动提取发票信息。
3. 本期不做附件跨凭证复用管理。
4. 本期不改造凭证核心借贷平衡、审核、过账或结账规则。

## 2. 业务范围

### 2.1 本期纳入

| 场景 | 本期能力 |
| --- | --- |
| 录凭证 | 新增凭证时支持手动上传附件，保存凭证后附件绑定到该凭证 |
| 查凭证 | 凭证列表展示附件数量，支持查看、上传、下载、删除附件 |
| 编辑凭证 | 编辑已有凭证时支持查看和维护附件 |
| 打印 | 凭证打印时展示附件张数，并支持按配置打印附件或附件清单 |
| 权限与日志 | 上传、删除、下载、打印附件受权限控制，并记录操作日志 |

### 2.2 本期不纳入

| 场景 | 说明 |
| --- | --- |
| 自动采集附件 | 发票采集、银行流水、业务单据自动回传暂不纳入本期 |
| 附件审批流 | 附件单独提交、单独审核暂不纳入本期 |
| 附件内容结构化 | 不对 PDF、图片、Excel 内容做结构化入库 |
| 批量附件归档 | 批量打包归档、长期冷存储策略暂不展开 |

## 3. 用户角色

| 角色 | 核心诉求 | 关键权限 |
| --- | --- | --- |
| 制单人 | 录入凭证时上传业务佐证材料，后续可补充或修正附件 | 上传、查看、删除本人有权维护的附件 |
| 审核人 | 审核凭证时查看附件是否完整、真实 | 查看、下载、打印附件 |
| 账套管理员 | 管理账套附件容量、权限和异常文件 | 查看、上传、删除、下载、打印 |
| 审计/查看人员 | 追溯凭证依据，查看附件和打印凭证材料 | 查看、下载、打印，默认不可修改 |

## 4. 核心业务规则

### 4.1 凭证与附件关系

1. 一张凭证可以绑定 `0` 个、`1` 个或多个附件。
2. 一个手动上传附件默认只绑定到一张凭证。
3. 附件不改变凭证分录本身的借贷金额、摘要、科目、制单人、审核状态。
4. 附件数量应在凭证列表、凭证详情、编辑页和打印页保持一致。
5. 凭证删除、红冲或作废后，附件不应被物理删除，应保留审计追溯记录。

### 4.2 附件来源

本期附件来源包括：

| 来源 | 说明 |
| --- | --- |
| 手动上传 | 用户在录凭证、查凭证、编辑凭证中主动上传 |
| 历史附件 | 迭代上线前已存在的凭证附件数据 |

后续可扩展来源包括：发票采集、银行流水、智能记账、业务系统回传。

### 4.3 常见附件类型

- 发票：销项发票、进项发票、费用发票。
- 银行单据：银行回单、流水截图、收付款凭证。
- 工资社保：工资表、社保公积金缴费单、个税申报表。
- 合同与结算：销售合同、采购合同、对账单、结算单。
- 税务与结转：申报表、结转测算表、成本结转明细。
- 其他：审批单、说明文件、截图类佐证材料。

## 5. 用户故事与验收标准

### US-01 录凭证时上传附件

**As a** 制单人  
**I want to** 在新增凭证时直接上传业务附件  
**So that** 凭证保存后就能带有完整佐证材料

**验收标准**

1. Given 用户进入录凭证页面  
   When 页面初始化完成  
   Then 页面展示附件上传入口和当前附件数量。

2. Given 用户尚未保存凭证  
   When 上传附件成功  
   Then 附件进入临时绑定状态，并在页面中展示文件名、大小、上传进度和删除入口。

3. Given 用户已上传附件但取消录凭证  
   When 用户确认离开或取消  
   Then 临时附件不绑定到正式凭证，并按系统清理策略处理。

4. Given 用户已上传附件并保存凭证成功  
   When 凭证生成正式编号  
   Then 附件绑定到该凭证，附件数量同步更新。

### US-02 查凭证时查看和补传附件

**As a** 财务人员  
**I want to** 在查凭证列表中看到附件数量并补传附件  
**So that** 我可以快速发现资料缺失并补齐

**验收标准**

1. Given 用户进入查凭证页面  
   When 凭证列表加载完成  
   Then “附单据/附件”列展示每张凭证的附件数量，例如 `0张`、`1张`、`7张`。

2. Given 用户点击附件数量  
   When 用户有查看权限  
   Then 打开“单据附件”弹窗，展示当前凭证附件列表、预览区和上传入口。

3. Given 用户在弹窗内上传附件成功  
   When 返回凭证列表  
   Then 当前凭证附件数量同步增加。

4. Given 用户没有附件查看权限  
   When 点击附件数量  
   Then 系统提示无权限，不展示附件内容。

### US-03 编辑凭证时维护附件

**As a** 制单人或账套管理员  
**I want to** 在编辑凭证时补充、删除或替换附件  
**So that** 我可以保持凭证资料与实际业务一致

**验收标准**

1. Given 用户打开编辑凭证页面  
   When 凭证存在附件  
   Then 页面展示附件数量、附件列表入口和最近上传信息。

2. Given 用户上传新附件  
   When 上传成功  
   Then 附件绑定到当前凭证，编辑页附件数量更新。

3. Given 用户删除附件  
   When 用户确认删除且有权限  
   Then 附件状态变更为已删除，页面不再展示为有效附件，系统记录操作日志。

4. Given 当前凭证处于已结账、已归档或锁定期间  
   When 用户尝试上传、删除或替换附件  
   Then 系统按权限和期间规则控制是否允许操作。

### US-04 打印凭证时体现附件信息

**As a** 财务人员或审计人员  
**I want to** 打印凭证时能体现附件张数，并按需打印附件  
**So that** 纸质归档或审计资料保持完整

**验收标准**

1. Given 凭证存在附件  
   When 用户打印凭证  
   Then 凭证打印版展示附件张数。

2. Given 用户选择“打印凭证及附件”  
   When 附件格式支持打印  
   Then 系统按凭证顺序输出凭证页和附件页。

3. Given 附件格式不支持直接打印  
   When 用户打印附件  
   Then 系统在附件清单中展示文件名、类型、上传人、上传时间，并提示该附件需下载后查看。

4. Given 用户无附件打印权限  
   When 打印凭证  
   Then 仅允许打印凭证正文，不输出附件内容。

## 6. 页面功能说明

### 6.1 录凭证页面

#### 6.1.1 入口位置

- 在凭证录入区域增加“附件”模块。
- 模块展示当前附件数量，例如 `附件 0张`。
- 提供“上传附件”按钮。
- 上传后展示附件列表，至少包含附件名称、文件大小、上传状态、删除操作。

#### 6.1.2 交互规则

1. 用户可在保存凭证前上传附件。
2. 上传中的附件应展示进度或处理中状态。
3. 上传失败时展示失败原因，并允许重新上传。
4. 凭证保存失败时，不应生成正式附件绑定关系。
5. 页面离开前如存在已上传但未保存的临时附件，应提示用户确认。

### 6.2 查凭证页面

#### 6.2.1 附件数量入口

- 凭证列表保留“附单据/附件”列。
- 数量区域使用可点击样式，明确表达可查看。
- 附件数量为 `0张` 时仍可点击进入上传。
- 列表刷新、上传成功、删除成功后，数量应同步刷新。

#### 6.2.2 单据附件弹窗

弹窗包含以下区域：

| 区域 | 内容 |
| --- | --- |
| 标题区 | 展示“单据附件”和凭证字号/凭证日期 |
| 统计区 | 展示附件总数、当前预览序号、附件空间使用量 |
| 操作区 | 上传、下载、删除、打印附件，按权限展示 |
| 列表区 | 展示附件名称、类型、大小、来源、上传人、上传时间 |
| 预览区 | 支持图片、PDF 预览；不支持预览的文件展示文件图标和下载入口 |

### 6.3 编辑凭证页面

#### 6.3.1 入口位置

- 在编辑凭证页面展示与录凭证一致的附件模块。
- 已有附件默认展示在附件列表中。
- 如凭证状态不允许维护附件，上传和删除操作置灰或隐藏，并展示原因。

#### 6.3.2 编辑影响

1. 修改凭证分录不影响已绑定附件。
2. 删除附件不影响凭证分录。
3. 保存凭证修改时，附件变更和凭证变更应分别记录日志。
4. 附件维护失败不应导致凭证分录保存结果被误判，具体事务策略需由技术方案确认。

### 6.4 打印功能

#### 6.4.1 打印入口

打印入口涉及以下位置：

| 入口 | 影响 |
| --- | --- |
| 查凭证列表打印 | 支持打印选中凭证，并按配置决定是否包含附件 |
| 凭证详情/编辑页打印 | 支持打印当前凭证，并按配置决定是否包含附件 |
| 附件弹窗打印 | 支持单独打印当前附件或附件清单 |

#### 6.4.2 打印模式

| 模式 | 说明 |
| --- | --- |
| 仅打印凭证 | 只输出凭证正文，凭证上展示附件张数 |
| 打印凭证及附件 | 输出凭证正文和可打印附件内容 |
| 仅打印附件清单 | 输出附件列表信息，不输出附件原文 |
| 仅打印当前附件 | 在附件弹窗中打印当前预览附件 |

#### 6.4.3 打印规则

1. 凭证正文上的附件张数取有效附件数量，不包含已删除附件。
2. 批量打印多张凭证时，应按凭证顺序输出，每张凭证后跟随该凭证附件。
3. 图片、PDF 可直接进入打印预览。
4. Word、Excel、压缩包等不支持在线打印的文件，进入附件清单，不直接转印。
5. 打印附件时应记录操作日志，至少包含操作人、操作时间、凭证 ID、附件 ID、打印模式。

## 7. 上传与文件规则

### 7.1 支持格式

建议支持以下格式：

| 类型 | 格式 |
| --- | --- |
| 图片 | `jpg`、`jpeg`、`png`、`bmp`、`webp` |
| 文档 | `pdf`、`doc`、`docx`、`xls`、`xlsx` |
| 压缩包 | `zip`、`rar`、`7z` |
| 其他 | 可由系统配置扩展 |

### 7.2 文件限制

1. 单个文件大小受系统配置限制。
2. 单张凭证附件数量受系统配置限制。
3. 单个账套附件总容量受系统配置限制。
4. 文件名保留原始名称，系统生成唯一文件标识，避免同名覆盖。
5. 上传成功后自动记录上传人、上传时间、文件大小、文件类型、附件来源。

### 7.3 同名文件处理

同一凭证下上传同名文件时，建议系统提示用户选择：

| 处理方式 | 说明 |
| --- | --- |
| 保留两份 | 新文件按同名副本保存，例如 `发票.pdf`、`发票(1).pdf` |
| 替换原文件 | 原附件状态变更为已替换，新附件成为有效附件 |
| 取消上传 | 不保存新文件 |

## 8. 权限与状态控制

### 8.1 权限矩阵

| 操作 | 制单人 | 审核人 | 账套管理员 | 审计/查看人员 |
| --- | --- | --- | --- | --- |
| 查看附件数量 | Y | Y | Y | Y |
| 查看附件内容 | Y | Y | Y | Y |
| 上传附件 | Y | N | Y | N |
| 删除附件 | Y | N | Y | N |
| 下载附件 | Y | Y | Y | Y |
| 打印附件 | Y | Y | Y | Y |
| 查看操作日志 | N | N | Y | N |

实际权限以系统角色配置为准，以上为默认建议。

### 8.2 凭证状态控制

| 凭证状态 | 查看 | 上传 | 删除 | 打印 |
| --- | --- | --- | --- | --- |
| 草稿/未审核 | 允许 | 允许 | 允许 | 允许 |
| 已审核 | 允许 | 按权限允许 | 按权限允许 | 允许 |
| 已结账 | 允许 | 默认禁止，可配置补传 | 默认禁止 | 允许 |
| 已归档 | 允许 | 禁止 | 禁止 | 允许 |
| 已作废/红冲 | 允许 | 禁止 | 禁止 | 允许 |

如业务允许已结账期间补传附件，需填写补传原因并记录日志。

## 10. 异常与边界

1. 凭证无附件时，附件弹窗仍可打开，并展示空状态和上传入口。
2. 上传空文件、超出大小限制、格式不支持时，应阻止上传并提示原因。
3. 上传失败时不改变凭证附件数量。
4. 网络中断时保留原附件列表，并提示用户稍后重试。
5. 附件无法预览时，展示文件图标、名称、大小和下载入口。
6. 多人同时上传或删除时，以服务端最终附件列表为准，前端刷新后展示最新数量。
7. 用户无查看权限时，可按产品策略选择展示数量但不展示内容，或完全隐藏附件列。
8. 临时附件清理策略需避免误删已正式绑定附件。
9. 病毒扫描或安全校验失败的文件不得绑定到凭证。

## 11. 指标与埋点建议

| 指标 | 用途 |
| --- | --- |
| 附件上传成功率 | 判断上传能力稳定性 |
| 附件上传失败原因分布 | 定位格式、大小、网络等问题 |
| 每张凭证平均附件数 | 评估功能使用强度 |
| 打印凭证及附件次数 | 评估打印联动使用情况 |
| 已结账期间补传次数 | 监控补传规则是否被频繁触发 |
| 附件删除次数 | 识别异常删除或流程不清晰问题 |

## 12. 验收清单

### 12.1 功能验收

- 录凭证页面可上传、查看、删除未保存凭证的临时附件。
- 凭证保存成功后，临时附件正式绑定到凭证。
- 查凭证列表展示附件数量，点击后可打开附件弹窗。
- 查凭证弹窗可上传、预览、下载、删除附件。
- 编辑凭证页面可查看和维护当前凭证附件。
- 附件上传、删除后，录凭证/查凭证/编辑凭证中的附件数量保持一致。
- 凭证打印版展示有效附件张数。
- 打印时支持仅打印凭证、打印凭证及附件、仅打印附件清单、仅打印当前附件。

### 12.2 权限验收

- 无上传权限用户不能上传附件。
- 无删除权限用户不能删除附件。
- 无查看权限用户不能查看附件内容。
- 已结账、已归档、已作废或红冲凭证遵守状态限制。
- 已结账期间补传附件时，如配置允许，必须记录补传原因。

### 12.3 数据与日志验收

- 上传成功后记录附件元数据。
- 删除附件后不物理删除文件记录，状态变更为已删除。
- 上传、删除、替换、下载、打印操作均记录日志。
- 凭证附件数量只统计有效附件。
- 批量打印时凭证与附件顺序正确。

## 13. 待确认事项

以下问题需要产品、业务或技术评审时确认：

1. 单个附件最大大小、单张凭证最大附件数、单账套总容量限制是多少。
2. 已审核但未结账凭证是否允许普通制单人继续补传或删除附件。
3. 已结账期间是否允许补传附件，如允许，是否必须填写补传原因。
4. 凭证打印默认模式是“仅打印凭证”还是“打印凭证及附件”。
5. 附件张数口径是否按文件数统计，还是图片/PDF 页数也要折算为张数。
6. Word、Excel 是否需要服务端转换为 PDF 后打印，还是仅进入附件清单。
7. 附件删除是否需要二次确认或填写删除原因。
8. 是否需要配置关键凭证类型的附件必传规则。
9. 查凭证列表附件列名称沿用“附单据”，还是统一调整为“附件”。
10. 用户无查看权限时，是否仍展示附件数量。
