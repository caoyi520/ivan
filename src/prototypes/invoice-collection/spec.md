# 发票采集页面

## 📋 业务与功能

### 1.1 核心目标

发票采集页面面向财务、行政或报销审核人员，用于集中上传、识别、校验和提交发票。页面强调“快速录入、及时发现异常、批量提交”，帮助用户减少手工录入和漏检风险。

### 1.2 功能清单

- **采集概览**：展示今日采集量、待校验、异常票据、预计可报销金额等关键指标。
- **上传入口**：支持拖拽上传、选择文件、查看支持格式与单次采集提示。
- **发票列表**：展示已采集发票，支持按状态识别当前处理进度。
- **识别结果**：展示发票代码、号码、开票日期、销售方、金额、税额等结构化字段。
- **校验面板**：提示重复发票、抬头不匹配、金额超限等风险项。
- **提交操作**：支持保存草稿、重新识别、提交审核。

### 1.3 交互要点

- 点击发票列表项：切换当前选中发票，刷新右侧识别结果与校验信息。
- 点击“模拟上传”：新增一张待校验发票并选中，触发 `onInvoiceUpload` 事件。
- 点击“重新识别”：将当前发票状态切换为识别中，再回到待校验状态，触发 `onReRecognize` 事件。
- 点击“提交审核”：将当前发票标记为已提交，触发 `onSubmitInvoice` 事件。
- 点击“保存草稿”：触发 `onSaveDraft` 事件，用于外部记录当前采集进度。

## 📊 内容规划

### 2.1 信息架构

```text
发票采集页面
├── 顶部任务栏
│   ├── 页面标题与任务说明
│   └── 操作按钮
├── 采集概览
│   ├── 今日采集
│   ├── 待校验
│   ├── 异常票据

├── 主工作区
│   ├── 左侧采集队列
│   │   ├── 上传入口

│   └── 右侧处理详情
│       ├── 流程步骤
│       ├── 识别结果
│       ├── 校验面板
│       └── 提交操作
```

### 2.2 数据来源

- **数据类型**：发票列表
- **数据源**：生成示例数据，可由外部 `data.invoices` 覆盖
- **关键字段**：
  - `id`: 发票唯一标识
  - `title`: 发票名称
  - `seller`: 销售方名称
  - `buyer`: 购买方名称
  - `invoiceNo`: 发票号码
  - `invoiceCode`: 发票代码
  - `date`: 开票日期
  - `amount`: 不含税金额
  - `tax`: 税额
  - `total`: 价税合计
  - `status`: 当前状态（recognizing / pending / warning / submitted）
  - `issues`: 校验提示列表

### 2.3 内容示例

- 发票名称：办公用品增值税电子普通发票
- 销售方：上海晨光科力普办公用品有限公司
- 购买方：某某科技有限公司
- 校验提示：抬头匹配、金额未超限、疑似重复发票需复核

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：单页工作台，顶部概览 + 左右分栏处理区
- **容器宽度**：流式
- **关键尺寸**：
  - 顶部任务栏：自适应高度，左右分布
  - 指标概览：桌面端四列，移动端两列或单列
  - 左侧采集队列：桌面端约 36% 宽度
  - 右侧处理详情：桌面端约 64% 宽度

### 3.2 响应式适配

- **桌面端（≥1200px）**：主工作区左右分栏，列表和详情同时可见。
- **平板端（768-1199px）**：维持左右分栏，但上传区和列表间距收紧。
- **移动端（<768px）**：主工作区改为单列，顶部操作按钮换行，识别字段两列变一列。

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

**说明**：页面使用 Ant Design 组件体系与克制的工作台视觉，强调信息扫描效率和表单可读性。

### 4.2 自定义设计要点

**自定义色彩**：
- 采集主色：`#2563eb` - 主按钮、进度和选中态
- 风险提示：`#b45309` - 校验警告
- 成功状态：`#15803d` - 已提交与通过校验

**自定义尺寸**：
- 主容器内边距：`24px`
- 卡片圆角：`8px`
- 上传区域最小高度：`168px`

### 4.3 组件状态

- **默认态（default）**：白色信息面板、浅灰页面背景、清晰分区。
- **悬停态（hover）**：发票列表项边框和背景轻微高亮。
- **选中态（selected）**：发票列表项显示蓝色边框和浅蓝背景。
- **加载态（loading）**：识别中发票展示进度条与蓝色状态标签。
- **异常态（warning）**：风险项使用琥珀色提示，保留可继续提交的操作路径。
- **完成态（submitted）**：提交成功后展示绿色状态标签与完成步骤。

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onInvoiceSelect` | `string` | 切换发票列表项 | 返回当前发票 JSON 字符串 |
| `onInvoiceUpload` | `string` | 点击模拟上传 | 返回新增发票 JSON 字符串 |
| `onReRecognize` | `string` | 点击重新识别 | 返回当前发票 JSON 字符串 |
| `onSubmitInvoice` | `string` | 点击提交审核 | 返回当前发票 JSON 字符串 |
| `onSaveDraft` | `string` | 点击保存草稿 | 返回当前采集状态 JSON 字符串 |

### 5.2 动作列表（actionList）

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `submit_current_invoice` | `string` | 可为空 | 提交当前选中发票 |
| `add_invoice` | `string` | 发票 JSON 字符串 | 向采集队列追加一张发票 |

### 5.3 变量列表（varList）

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `selected_invoice` | `object` | 第一张发票 | 当前选中的发票 |
| `invoice_count` | `number` | 示例数据数量 | 当前采集队列数量 |

**命名规范**：使用 snake_case（小写字母、数字、下划线）

### 5.4 配置项列表（configList）

| 配置项名称 | 类型 | 默认值 | 说明 |
|----------|-----|-------|------|
| `title` | `string` | 发票采集 | 页面标题 |
| `subtitle` | `string` | 上传、识别并校验报销发票 | 页面说明 |

### 5.5 数据项列表（dataList）

**数据结构**：

```typescript
{
  id: string;
  title: string;
  seller: string;
  buyer: string;
  invoiceNo: string;
  invoiceCode: string;
  date: string;
  amount: number;
  tax: number;
  total: number;
  status: 'recognizing' | 'pending' | 'warning' | 'submitted';
  issues: string[];
```
