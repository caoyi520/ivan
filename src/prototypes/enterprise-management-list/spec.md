# 企业管理 · 企业列表

## 1. 业务与功能

### 1.1 页面定位与核心目标

本页面是服务商后台的企业管理工作台，用于按企业、商品、服务状态、人员、账期和更新时间等条件检索企业，并集中查看服务、账套、税务与派工状态。当前提交保留用户确认的独立 HTML 业务语义，并重点完善左侧功能导航的高密度交互。

### 1.2 功能清单

- 企业综合搜索与多维组合筛选。
- 全部、待服务、服务中三个列表视图。
- 批量开通、分配记账会计、添加标签和导出入口。
- 企业账套、电子税务局、个税扣缴端、财务信息和标签列筛选。
- 企业服务状态、账套状态、税务状态、派工信息及标签展示。
- 左侧九个业务分组的手风琴导航和全部展开控制。

### 1.3 交互要点

- 默认只展开包含当前页面的“企业管理”分组，降低长菜单滚动成本。
- 展开一个新分组时自动收起其他分组；顶部可切换“全部展开 / 收起其他”。
- 分组标题支持鼠标、Enter、Space、方向键、Home 和 End；菜单项支持 Esc 收起并返回分组标题。
- 展开状态同步 `aria-expanded`、`aria-controls`、`aria-hidden` 与 `inert`，当前菜单项使用 `aria-current="page"`。
- 侧栏与主内容区独立滚动，顶部栏固定在视口内。
- 尊重 `prefers-reduced-motion`，关闭动画时不影响菜单状态切换。

## 3. 布局与结构

### 3.1 整体布局

- 使用“固定顶部栏 + 左侧窄导航 + 右侧高密度表格工作区”的双栏布局。
- 顶部栏高度 52px；左侧导航宽度 176px。
- 页面高度锁定为浏览器视口高度，侧栏与主工作区分别滚动。
- 表格保留横向滚动，固定企业标识列和操作列，避免压缩业务字段。

### 3.2 响应式策略

- 当前业务桌面端最小宽度为 1180px。
- 在 1168×978 验证视口下，菜单文字保持单行省略，不发生纵向挤压换行。
- 更窄终端暂不提供移动端重排，属于后续业务适配范围。

## 4. 视觉规范

### 4.1 设计规范来源

- 用户确认的企业列表视觉基线。
- 高密度 B 端工作台规范：浅灰蓝工作区、白色业务面、紫蓝主操作、细边框和紧凑字号。

### 4.2 自定义设计要点

- 导航分组标题高 36px，菜单项高 34px。
- Hover 和焦点使用浅紫背景；当前项增加浅紫底和左侧 3px 主色标识。
- 分组展开使用 160–180ms 的高度与透明度过渡。
- 导航顶部操作区吸顶，长菜单滚动时始终保留展开控制。

### 4.3 组件状态

- 默认：当前业务组展开，其他组收起。
- Hover：标题或菜单项使用浅紫背景与主色文字。
- Focus-visible：显示内描边焦点环。
- Expanded：箭头向下，菜单内容可聚焦。
- Collapsed：箭头旋转，菜单内容不可聚焦。
- Active：浅紫背景、主色文字、左侧选中条及 `aria-current`。

## 5. 实现与验收边界

- `index.tsx` 使用受限 `iframe srcDoc` 承载 `source-document.txt` 中的原始独立页面，确保其内联样式和脚本保持一致；使用文本扩展名是为了避免仓库开发路由将原型目录中的 `.html` 误识别为页面入口。
- iframe 仅允许表单与脚本运行，不授予同源、弹窗或顶层导航权限。
- 本原型为演示版本；保存、导出、批量开通等操作只提供前端反馈，不产生真实业务数据。
- 验收需覆盖构建成功、页面加载、分组切换、全部展开、键盘焦点及控制台错误。
