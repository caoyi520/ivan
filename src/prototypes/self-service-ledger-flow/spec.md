# 猪哥云自助导账系统规格说明

## 1. 业务与功能

### 1.1 页面定位

猪哥云自助导账系统面向企业用户和服务商运营人员，帮助用户连接源财务软件、采集账套资料、核对异常信息、配置迁移规则，并将数据迁移到目标财务软件。系统以真实对外服务场景设计，登录前只展示独立登录页，登录后进入业务工作台。

### 1.2 核心目标

- 用户可使用企业账号独立登录导账系统。
- 登录后进入单页导账工作台，所有操作在同一页面内通过记录列表、面包屑和右侧抽屉完成。
- 工作台采用真实数据表格展示全部导账状态，支持搜索、状态筛选、列排序和按状态查看详情；列表不提供复选框。
- 每个功能页的关键对象均可点击查看详情，包括导账记录、统计指标、采集记录、账套、迁移内容、处理阶段、操作记录。
- 顶栏仅保留系统品牌、用户偏好和退出登录。
- 页面文案面向真实用户，不出现内部设计或开发类词语。
- 数据不只做静态展示，用户可以搜索、填写、选择、切换、查看详情、提交采集和提交迁移。

### 1.3 功能清单

- **独立登录页**：品牌信息、系统能力摘要、账号密码登录。
- **工作台**：导账记录统计、待确认账套、成功率、全状态导账记录表格、搜索、筛选、排序和按状态查看详情。
- **新建采集**：从右侧抽屉选择源财务软件，填写服务商名称、源系统账号和密码，提交采集。
- **采集详情**：采集成功、部分采集成功记录可进入；通过“采集成功 / 采集异常”切换展示各自数量和账套数据，采集成功页支持复选和全选，选择后进入迁移配置。
- **迁移配置**：确认匹配方式、迁移方式、迁移内容和目标财务软件授权后提交迁移。
- **迁移详情**：迁移成功、部分迁移成功记录可进入；通过“迁移成功 / 迁移异常”切换展示各自数量和账套迁移情况。
- **详情抽屉**：统一承载记录、账套、配置说明、处理阶段和操作记录的详情。

### 1.4 交互要点

- 未登录时不展示业务工作台。
- 点击“登录”进入工作台，右上角支持退出。
- 工作台统计卡片、记录列表和“查看”按钮都能在当前页展示相应数据。
- 工作台表格支持按记录编号、企业、状态、账套数量、最近活动排序，不显示复选框。
- 点击“新建采集”从右侧抽屉填写并提交；提交后关闭抽屉，回到工作台首页等待采集结果。
- 采集成功、部分采集成功记录显示“查看采集详情”，进入后可在“采集成功 / 采集异常”中切换，并可全选或复选采集成功账套进入迁移配置。
- 迁移配置确认后提交迁移。
- 提交迁移后回到工作台，记录进入迁移中状态，等待迁移结果返回。
- 迁移成功、部分迁移成功记录显示“查看迁移详情”，进入后可在“迁移成功 / 迁移异常”中切换查看账套迁移情况。
- 不提供固定流程导航条；用户从导账记录逐步进入采集详情或迁移详情。
- 面包屑按“首页 / 导账工作台 / 当前步骤”展示，点击“首页”或“导账工作台”返回记录列表。
- 采集中、采集失败记录不可操作；迁移中记录显示等待迁移结果。
- 迁移成功后可查看每个成功账套的目标账套编号、期间、凭证、发票、附件和金额。
- 右侧栏仅展示操作日志，日志包含操作内容和操作时间，并可点击查看详情。

## 2. 内容规划

### 2.1 信息架构

```text
猪哥云自助导账系统
├── 登录页
│   ├── 系统能力说明
│   ├── 账号
│   ├── 密码
│   └── 登录
└── 业务工作台
    ├── 顶部状态栏
    │   ├── 系统品牌
    │   ├── 用户偏好
    │   └── 退出
    ├── 中央业务区
    │   ├── 导账记录列表
    │   ├── 采集详情
    │   ├── 迁移配置
    │   └── 迁移详情
    ├── 右侧操作日志
    │   └── 操作记录
    ├── 新建采集抽屉
    └── 详情抽屉
        ├── 详情标题
        ├── 分组信息
        └── 可执行操作
```

### 2.2 数据来源

- **数据类型**：导账记录、账套资料、采集记录、迁移状态记录、迁移成功账套明细、迁移设置、操作记录。
- **数据源**：根据本次导图整理生成示例业务数据。
- **关键字段**：
  - `recordId`: 导账记录编号。
  - `sourceSoftware`: 源财务软件。
  - `targetSoftware`: 目标财务软件。
  - `merchant`: 商户/服务商名称。
  - `startTime`: 采集开始时间。
  - `endTime`: 采集结束时间。
  - `status`: 当前处理状态。
  - `ledgerName`: 账套名称。
  - `creditCode`: 统一社会信用代码。
  - `taxType`: 纳税性质。
  - `accountingStandard`: 会计准则。
  - `risk`: 异常说明和处理建议。

### 2.3 内容示例

- 财务软件：猪哥云、财税合规 AI 服务系统、亿企赢。
- 匹配方式：按账套名称、按统一社会信用代码、按账套名称 + 统一社会信用代码。
- 迁移方式：跳过已创建账套的企业、覆盖已创建账套的企业。
- 迁移内容：销项发票、进项发票、费用报销、无票收入、银行、工资、财务初始余额、会计科目、记账凭证、辅助核算、币别、附件、小计、银行账户、操作日志、库存、资产。

## 3. 布局与结构

### 3.1 整体布局

- **登录页**：左侧系统说明区 + 右侧登录卡片。
- **登录后页面**：顶部状态栏 + 单页中央业务区 + 右侧操作日志。
- **详情查看**：右侧抽屉，覆盖在当前页面之上，关闭后回到原操作位置。

### 3.2 响应式适配

- **桌面端（≥1200px）**：主工作台和右侧操作日志并排，抽屉从右侧展开。
- **平板端（768-1199px）**：主工作台和右侧操作日志上下排列。
- **移动端（<768px）**：登录页、功能区、详情区均单列展示。

## 4. 视觉规范

### 4.1 设计规范来源

**设计规范来源**：本次导图整理出的导账闭环与真实对外系统使用场景，不再参考上一轮 UI 规范。

**说明**：视觉回到业务系统方向，重点强化单页导账记录入口、右侧抽屉新建采集、面包屑返回、采集详情账套选择、迁移配置确认、操作日志，以及迁移详情的明细追溯。

### 4.2 自定义设计要点

- 主色使用业务蓝，用于主按钮、当前导航、重要操作和通知徽章。
- 背景使用浅灰蓝，卡片使用白色，边框使用灰蓝色。
- 成功、警告、错误、信息状态分别使用 `#10B981`、`#F59E0B`、`#EF4444`、`#3B82F6`。
- 顶部栏、面包屑和内容区以真实业务工作台的可读性为主，不绑定上一轮规范尺寸。
- 卡片和控件使用克制圆角、轻阴影和细边框建立层级。
- 中文字体使用 `"PingFang SC", "Microsoft YaHei"`。

### 4.3 组件状态

- **默认态**：白色卡片、灰蓝边框、浅灰背景。
- **悬停态**：可点击卡片、表格行和按钮边框加深，背景轻微高亮。
- **选中态**：当前导航和当前配置项高亮。
- **操作态**：不同状态展示不同操作，包括查看采集详情、查看迁移详情、等待迁移结果和不可操作。
- **禁用态**：异常账套不可勾选，但可点击查看详情。
- **警示态**：覆盖迁移、字段缺失、处理失败使用橙红提示。
- **完成态**：绿色标签和完成进度。

## 5. Axure API 说明

### 5.1 事件列表

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `on_page_change` | `string` | 切换功能页 | 返回页面 key |
| `on_login_submit` | `string` | 提交登录 | 返回登录账号 |
| `on_record_detail_open` | `string` | 打开记录详情 | 返回详情信息 |
| `on_ledger_detail_open` | `string` | 打开账套详情 | 返回账套信息 |
| `on_collect_submit` | `string` | 提交采集 | 返回源软件授权信息 |
| `on_migration_submit` | `string` | 提交迁移 | 返回迁移配置 |
