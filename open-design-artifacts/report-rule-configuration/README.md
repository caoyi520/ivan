# 报表及规则配置后台 Open Design Artifact

这是从本地原型 `src/prototypes/report-rule-configuration` 生成的 Open Design 预览产物。

## 文件

- `index.html`：可直接预览的入口文件
- `report-rule-configuration.js`：原型构建后的组件脚本
- `assets/html-template-bootstrap.js`：Axhub HTML 模板运行时
- `artifact.json`：Open Design artifact 元数据
- `data.json`：预览摘要数据
- `provenance.json`：来源与生成说明

## 预览

直接打开 `index.html`，或在 Open Design 中选择该目录作为 HTML artifact 预览。
